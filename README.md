## ✨ Features

- **Cinematic Full-Screen Hero:** Rich animated introduction with photo backdrop, gold ampersand, and smooth unveil.
- **Bilingual Invitation Message:** English and Malayalam blessings (*"മാതാപിതാക്കളുടെ അനുഗ്രഹത്തോടെ..."*).
- **Our Families Section:** Elegant balanced parental information cards.
- **Our Beautiful Moments Gallery:** 4-photo responsive grid with interactive full-screen Lightbox, swipe support, zoom, and image counter.
- **Live Countdown Timer:** Live timer counting down to 21 August 2027, 10:00 AM IST. Automatically displays *"Today marks the beginning of our forever."* upon completion.
- **Interactive RSVP via WhatsApp:** Form allowing guests to specify attendance, headcount, and wishes, automatically opening WhatsApp with a formatted message.
- **Multi-Platform Sharing:** 1-click sharing to WhatsApp, Facebook, native mobile share sheet, and link copying.
- **Romantic Background Music:** Floating vinyl audio player playing peaceful ambient acoustic melodies, with Web Audio API procedural synthesis fallback.
- **Floating Floral & Gold Kasavu Petals:** 60fps canvas particles creating a magical Kerala wedding atmosphere.
